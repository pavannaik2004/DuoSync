> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the product for demo day: each theme restyles the lobby, attempt and results pages; sound effects with a remembered mute; short animations; the remaining Could items (CHAT-6, AUTH-7, SCORE-6); the §11 acceptance checks pinned by tests or a written check; a load check for NFR-10/13; a README and demo script. PRD §11 Phase 6 gate: *every acceptance check passes on the hosted build.*

**Architecture:** Server changes are small and follow the existing MVC split: a chat burst limit in `sockets/handlers.js` (options on the runtime, like `submitGapMs`), `PATCH /api/users/me` in the user route/controller/new `profileService.updateProfile`, and a per-theme ranking aggregation in `services/rankingService.js` behind `GET /api/themes/:slug/rankings`. The player and result views gain `theme.styleKey`. On the client, `useThemeStyle(styleKey)` sets `data-theme` on `<html>` while a game page is mounted and loads that theme's Google Fonts; eight sheets under `src/styles/themes/` override the base tokens only. Audio is Web Audio synthesis (`src/audio/`), driven by a pure `cuesFor(prev, next)` that compares two attempt states.

**Tech Stack:** The Phase 5 stack (Node 22, Express 5, Mongoose 9, Socket.io 4, React 19, Vite 8). No new npm dependencies.

**Spec:** `PRD Collaborative Digital Escape Room.md` (§5.6 CHAT-6, §5.1 AUTH-7, §5.8 SCORE-6, §5.11 AUDIO, §5.12 UI-2/3/4/5, §8 NFR-1/4/10/13/14/15/16/17, §11 Phase 6 and the acceptance checks) and `docs/themed-puzzle-sets.md` (the style notes per theme: palette, fonts, texture, timer). Cross-phase rules are in `docs/superpowers/plans/2026-11-09-00-roadmap.md`. Read `DECISIONS.md` (D1–D96, plus D97–D108 below) and `CONTEXT.md` first.

**PRD requirements covered:** UI-2, UI-3 (re-checked), UI-4 (re-checked), UI-5, AUDIO-1, AUDIO-2, CHAT-6, AUTH-7, SCORE-6, NFR-10/13 (load check), NFR-14 (warm-up in the demo script), NFR-15/16 (audit), DECISIONS Q6; the deferred minors listed in Task 5 and Task 10.

## Review Focus

1. **A burst of chat from two tabs of the same player.** The limit counts the player, not the socket, so 3 + 3 messages from two tabs in 3 s refuses the 6th. Test in Task 1.
2. **A username change to another player's name differing only in case** ("Alice" when "alice" exists) is 409 `USERNAME_TAKEN`; changing to your own name in different case ("ALICE" for alice) is allowed. Test in Task 2.
3. **Rankings for a team with several runs in one theme** list the team once, with its best run by §7.3 (points, then levels, then time, then finish time), and an in-progress or practice attempt never counts. Test in Task 3.
4. **Leaving a game page restores the default look.** Going from `/play/:code` to `/dashboard` puts `data-theme="default"` back, including after the results screen and on browser Back. Browser check in Task 7.
5. **Sound before any gesture or after a reconnect.** A page opened from a link plays nothing until the first click/key, and a reconnect snapshot never replays old cues. Browser check in Task 8 (an `AudioContext` that is never created before the gesture; `cuesFor(null, s)` returns `[]`).
